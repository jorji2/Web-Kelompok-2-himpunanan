    Materi Himpunan

    Pengertian

    Himpunan adalah kumpulan objek-objek yang berbeda, digunakan untuk mengelompokkan sejumlah objek. Objek dalam himpunan disebut elemen, unsur, atau anggota.

    Contoh: A = {1,2,3,4} menggambarkan himpunan A dengan 4 anggota, yaitu 1, 2, 3, dan 4.

    Jika himpunan berukuran besar atau tak terbatas, himpunan dapat digambarkan dengan mendaftar sifat yang diperlukan untuk menjadi anggota.

    Contoh: B = { x | x bilangan bulat genap positif }

    Karakteristik Himpunan

    Himpunan harus well-defined: secara definitif dapat dinyatakan apakah suatu objek merupakan elemen atau bukan elemen himpunan tersebut.

    S = {beberapa bilangan asli} bukan himpunan well-defined, sebab tidak dapat dinyatakan apakah 5 ∈ S atau 5 ∉ S.
    S = {empat bilangan asli pertama} well-defined, sebab elemennya dapat disebutkan secara definitif, yaitu 1, 2, 3, dan 4.

    Ekspresi Himpunan

    Himpunan dapat dinyatakan dengan menyebutkan sifat-sifatnya atau mendaftar elemen-elemennya. Misalnya himpunan bilangan prima yang kurang dari atau sama dengan 5 dapat ditulis {2,3,5} atau {x | x bilangan prima ≤ 5}.

    Jika a adalah salah satu elemen himpunan S, dinotasikan a ∈ S. Ada tepat satu himpunan yang tidak memiliki elemen, yaitu himpunan kosong, dinotasikan Ø.

    Cara Penyajian Himpunan

    1. Enumerasi elemen

    Menuliskan semua elemen himpunan di antara dua tanda kurung kurawal. Himpunan biasanya diberi nama dengan huruf kapital atau simbol lain.

    A = {1,2,3,4} adalah himpunan 4 bilangan asli pertama.

    2. Simbol-simbol baku

    PHimpunan bilangan bulat positif = {1, 2, 3, ...}
    NHimpunan bilangan alami (natural) = {1, 2, ...}
    ZHimpunan bilangan bulat = {..., -2, -1, 0, 1, 2, ...}
    QHimpunan bilangan rasional
    RHimpunan bilangan riil
    CHimpunan bilangan kompleks
    UHimpunan semesta (universal)

    Misalkan U = {1,2,3,4,5} dan A himpunan bagian dari U dengan A = {1,3,5}.

    3. Notasi pembentuk himpunan

    Notasi: { x | syarat yang harus dipenuhi x }

    • Bagian kiri tanda "|" melambangkan elemen himpunan.
    • Tanda "|" dibaca "di mana" atau "sedemikian sehingga".
    • Bagian kanan tanda "|" menunjukkan syarat keanggotaan.
    • Setiap tanda "," di dalam syarat keanggotaan dibaca "dan".

    A = himpunan bilangan bulat positif yang lebih kecil dari 5:
    A = {x | x bilangan bulat positif kurang dari 5} = {x | x ∈ P, x < 5} = {1,2,3,4}

    B = himpunan bilangan genap positif yang kurang dari atau sama dengan 8:
    B = {x | x/2 ∈ P, 2 ≤ x ≤ 8} = {2,4,6,8}

    4. Diagram Venn

    Menyajikan himpunan secara grafis. Himpunan semesta (U) digambarkan sebagai persegi panjang, sedangkan himpunan lainnya sebagai lingkaran di dalamnya.

    Misal U = {1,2,...,7,8}, A = {1,2,3,5}, B = {2,5,6,8}.

    Relasi Himpunan

    Himpunan bagian

    Himpunan B adalah himpunan bagian (subset) dari A, dinotasikan B ⊆ A atau A ⊇ B, jika setiap elemen B merupakan elemen A.

    Sejati dan tak sejati

    Untuk setiap himpunan A, himpunan A dan Ø keduanya merupakan himpunan bagian dari A. A disebut himpunan bagian tak sejati (improper subset), sedangkan himpunan bagian lainnya disebut himpunan bagian sejati (proper subset).

    S = {a,b,c} memiliki 8 himpunan bagian: Ø, {a}, {b}, {c}, {a,b}, {a,c}, {b,c}, {a,b,c}.

    Himpunan sama

    A dan B sama (A = B) jika dan hanya jika A ⊆ B dan B ⊆ A.

    A = {1,2,3,4} dan B = {3,2,4,1} adalah himpunan yang sama.

    Kardinalitas

    Jika A memiliki elemen yang berhingga banyaknya, jumlah elemen A disebut kardinal himpunan A. Notasi: n(A) atau |A|.

    B = {x | x bilangan prima kurang dari 20} = {2,3,5,7,11,13,17,19}, maka n(B) = 8.

    Himpunan Kosong

    Himpunan yang tidak memiliki satu pun elemen, atau kardinalnya 0. Notasi: Ø atau { }.

    E = {x | x < x}, maka n(E) = 0.
    P = {orang Indonesia yang pernah ke bulan}, maka n(P) = 0.

    Himpunan yang Ekuivalen

    Himpunan A ekuivalen dengan himpunan B jika dan hanya jika kardinal kedua himpunan sama. Notasi: A ~ B ↔ |A| = |B|.

    A = {1,3,5,7} dan B = {a,b,c,d}, maka A ~ B.

    Himpunan Saling Lepas

    Dua himpunan A dan B saling lepas (disjoint) jika keduanya tidak memiliki elemen yang sama. Notasi: A // B.

    A = {x | x ∈ P, x < 8} dan B = {20,30,...}, maka A // B.

    Himpunan Kuasa

    Himpunan kuasa (powerset) dari A adalah himpunan yang elemennya semua himpunan bagian dari A, termasuk himpunan kosong dan A sendiri. Notasi: P(A) atau 2A.

    A = {1,2}, maka P(A) = { { }, {1}, {2}, {1,2} } dan n(P(A)) = 4.

    Operasi terhadap Himpunan

    Irisan (intersection)

    Himpunan yang setiap elemennya merupakan elemen A dan elemen B.

    A ∩ B = { x | x ∈ A dan x ∈ B }

    Gabungan (union)

    Himpunan yang setiap anggotanya merupakan anggota A atau B.

    A ∪ B = { x | x ∈ A atau x ∈ B }

    Komplemen

    Himpunan yang elemennya merupakan elemen U yang bukan elemen A dan bukan elemen B.

    Ā = { x | x ∈ U dan x ∉ A }

    Selisih (A − C)

    Himpunan yang elemennya merupakan elemen A dan bukan elemen C.

    A − C = { x | x ∈ A dan x ∉ C } = A ∩ C̄

    Beda setangkup (symmetric difference)

    Himpunan yang elemennya ada pada A atau B tetapi tidak pada keduanya.

    A ⊕ B = (A ∪ B) − (A ∩ B) = (A − B) ∪ (B − A)

    Perkalian kartesian

    Himpunan yang elemennya semua pasangan berurutan (ordered pairs) dengan komponen pertama dari A dan komponen kedua dari B.

    A × B = { (a, b) | a ∈ A dan b ∈ B }

    C = {1,2,3} dan D = {a,b}, maka C × D = {(1,a),(1,b),(2,a),(2,b),(3,a),(3,b)}

    Sifat-sifat Operasi Himpunan

    HukumRumus
    IdentitasA ∪ Ø = A;   A ∩ U = A
    KomplemenA ∪ Ā = U;   A ∩ Ā = Ø
    Involusi(Ā)‾ = A
    NullA ∩ Ø = Ø;   A ∪ U = U
    IdempotenA ∪ A = A;   A ∩ A = A
    PenyerapanA ∪ (A ∩ B) = A;   A ∩ (A ∪ B) = A
